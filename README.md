🌊 Two as One: Faith & Journey Companion
Two as One is a web-based, privacy-first relational dashboard designed for couples. It blends daily faith practices, proactive communication tools, dynamic date generation, guided journal logging, and personal connection blueprints into a single, seamless shared interface.

🚀 Getting Started
Clone or Download: Save index.html, styles.css, and script.js into the same folder on your computer.

Launch Application: Open index.html in any web browser (Chrome, Edge, Safari, Firefox).

Usage:

Select your active profile at the top right.

Complete daily check-ins on The Hearth tab.

Use The Peace Table whenever you need structured space to process feelings.

Access Letters & Vault to generate journaling prompts based on your current emotional state.
